使用說明

這是一個方便查看與編輯 AI 生成的旅遊行程的小工具，目前以電腦版為主。修改時資料暫存在瀏覽器，按「儲存」寫回 .html 檔。免安裝、註冊或外部 API 金鑰。可以自行部署分享給其他人，手機也可以瀏覽編輯，只是部分功能不支援。

請 AI 排行程

  1. 點擊下方按鈕複製提示詞，貼給你的 AI。
  2. 在最後寫上旅行條件。已經有行程也可以直接貼上。
  3. 把 AI 回覆的 JSON 整段貼到下方框框，按「匯入」。
  4. 檢查後按左下「儲存」，就得到一個屬於你的行程嚕！

行程資料存在 HTML 裡 id 為 trip-data 的區塊，格式是提示詞裡的 JSON。大部分欄位都能省略，最少只要 {"days":[{"date":"2027-04-01","items":[{"n":"清水寺"}]}]}。


    

     
t開始時間，24 小時制

     
k類別，只能用提示詞列出的類別；transit 與 stay 會套用所在區域的顏色，而不是當天的顏色

     
lat lon緯度與經度，有座標才會出現在地圖上

     
qGoogle 地圖搜尋字詞

     
wiki英文維基條目名，用來找照片

     
alttrue 表示當天的備案

     
pool候選地點，還沒決定是否排入

     
events旅行期間當地的展覽、會議、節慶等活動

     
cats evCats地點與活動類別，在介面裡改過才會出現

     
theme改過的顏色，省略時用預設配色

     
updatedAt最後修改時間，手動編輯時省略

手動編輯

   
    
    
  • 「工具」>「重新開始」，從空白開始編輯。
    • 
    
  • 「＋新增一天」>「＋新增地點或行程」。
    • 
    
  • 開頭打時間會自動排序，例如 09:30 清水寺。
    • 
    
  • 按鉛筆編輯。按勾勾下方的圖釘自動定位。
    • 
    
  • 找不到位置時，貼上 Google 地圖網址（需要電腦版）。
    • 
    
  • 「地點」分頁可以存放候選地點，或設定成某天的備案。
    •

外部服務與限制
    
    
     
  • 地圖使用 Leaflet 與 Esri，載入失敗改用 OpenStreetMap。自動定位使用 Nominatim。照片來自 Wikipedia、Wikimedia Commons 與 Openverse。
    • 
     
  • 行程不會上傳到任何伺服器，只存在瀏覽器與檔案裡。定位和搜尋照片時，地點名稱會發送到以上的服務。
    • 
     
  • 離線時地圖和照片不會載入。冷門地點自動定位可能找不到，需使用 Google 地圖網址定位。
    • 
     
  • 地點、時間與開放資訊僅供參考，出發前請再確認。
